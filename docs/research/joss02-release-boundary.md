## Fixed-revision decision

The research-release boundary is **not frozen**. `B` is a clean source snapshot from which to review the current draft, not a tested release nomination. To close JOSS-02, the exact final paper and production code must be fixed together and the required security, workflow, compatibility, and negative tests must be recorded for that revision. Existing source and artifact links make the claims inspectable but do not supply that missing execution.
