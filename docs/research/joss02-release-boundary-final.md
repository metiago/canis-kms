## Release decision and impact

The candidate's architecture is unchanged by this JOSS-02 work: official JSSE TLS client/server, client-side envelope processing, and encrypted persistence. The release decision accepts the documented shared-access model for this **research candidate** and explicitly scopes app Issues #7, #8, and #36: invalid master-key/database material, malformed stored keys, public/private-key exposure, and missing-database replacement are covered by CODE-01 implementation and fixed tests, while two-move crash durability, path races, POSIX behavior, and per-key policy remain outside the verified boundary. No private key should appear in public responses; the server returns only public metadata or a recovered data key to admitted clients. This is a trust-model limitation, not an authorization bypass.

The operational impact is a tested Windows candidate and documented setup/fixture constraints. Production operators still need external secret and TLS provisioning, filesystem controls, host network controls for the server's wildcard bind, and exact matching backup material for the tested manual restore path. The candidate retains the valid `CANISDB1` and `CANISHYB1` formats and the official CANISP workflow; the CODE-01 client `Entry` public API no longer exposes a private-key field, as recorded in [CODE-01 compatibility limits](../code01-integrity.md#operational-and-compatibility-limits). Neither this document nor the smoke runs claim wire compatibility with a historical predecessor.

Remaining risks are unmeasured crash durability, cached master-key behavior, shared-access blast radius, missing audit integrity, single-host Windows study provenance, and incomplete independent candidate reproduction. Future improvements are deployment filesystem validation, POSIX fixed-candidate checks, an integrity-verifiable audit schema, optional per-key policy with revised research interpretation, and managed key rotation. The original local controls and availability study remain separate research work and were not performed for JOSS-02.
